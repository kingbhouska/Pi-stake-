# PiStake –  Staking Platform

PiStake is a front-end staking dashboard built for educational and presentation purposes.

⚠ DISCLAIMER:
This is a only. It does connect to the Pi Network blockchain.
No real staking, wallet interaction, or financial transactions occur on this platform.

---

## Features

- Demo user dashboard
- Simulated live profit counter
- Lock period options (30 / 90 / 180 days)
- ROI calculator
- Demo wallet connect UI
- Fully static front-end project

---

## Purpose

This project was created to demonstrate how a staking dashboard interface could look and function in a real Web3 environment.

It is intended for:
- UI/UX demonstration
- Investor presentation mockups
- Educational purposes
- Web development practice

---

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
